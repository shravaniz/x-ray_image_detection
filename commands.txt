Knee KL Grade Classification - 8 CNN Ensemble (paper code, Linux)
==================================================================

Repo   : https://github.com/shravaniz/x-ray_image_detection
Paper  : https://doi.org/10.1038/s41598-023-50210-4  (Pi et al., Sci Rep 13:22887, 2023)
Code   : official paper code (sunwxxpi/Knee-KL-Grade-Classification), 8 CNNs only
Targets: 8-model mix voting 76.33% acc / 0.7640 F1
         paper's best 6-model mix voting 76.93% acc / 0.7665 F1

# setup (once per shell)
cd /home/dumalkar/Documents/x-ray_image_detection/OAI-KL
source ../.venv/bin/activate

# 0) one-time: build the CSVs the scripts expect, from the Mendeley folders
#    train.csv = train + val (6,604 images, the paper's CV pool)
#    test_correct.csv = test (1,656 images, the paper's held-out set)
python make_csv.py --data-dir ../KneeXrayData/ClsKLData/kneeKL299

# 1) train the 8 CNNs (5-fold stratified CV, paper's Table-3 optimized sizes)
python main.py -m densenet_161       -i 512
python main.py -m efficientnet_b5    -i 448
python main.py -m efficientnet_v2_s  -i 456
python main.py -m regnet_y_8gf       -i 384
python main.py -m resnet_101         -i 384
python main.py -m resnext_50_32x4d   -i 512
python main.py -m wide_resnet_50_2   -i 456
python main.py -m shufflenet_v2_x2_0 -i 512

# or the same training as one bash loop
for m in densenet_161:512 efficientnet_b5:448 efficientnet_v2_s:456 \
         regnet_y_8gf:384 resnet_101:384 resnext_50_32x4d:512 \
         wide_resnet_50_2:456 shufflenet_v2_x2_0:512; do
  name="${m%%:*}"; size="${m##*:}"
  python main.py -m "$name" -i "$size"
done

# 2) TTA test predictions: one CSV per checkpoint in ./submission/<model>/(<size>, <size>)/
for m in densenet_161:512 efficientnet_b5:448 efficientnet_v2_s:456 \
         regnet_y_8gf:384 resnet_101:384 resnext_50_32x4d:512 \
         wide_resnet_50_2:456 shufflenet_v2_x2_0:512; do
  name="${m%%:*}"; size="${m##*:}"
  python test_auto.py -m "$name" -i "$size"
done

# 3) per-model accuracy / F1 scores
for m in densenet_161:512 efficientnet_b5:448 efficientnet_v2_s:456 \
         regnet_y_8gf:384 resnet_101:384 resnext_50_32x4d:512 \
         wide_resnet_50_2:456 shufflenet_v2_x2_0:512; do
  name="${m%%:*}"; size="${m##*:}"
  python score_auto.py -m "$name" -i "$size" -t 0.65
done

# 4) ensemble - all 8 models, hard / soft / mix voting
#    test_ensemble.py reads EVERY csv in the flat ./submission/ folder
rm -f ./submission/*.csv
cp ./submission/densenet_161/'(512, 512)'/*.csv       ./submission/
cp ./submission/efficientnet_b5/'(448, 448)'/*.csv    ./submission/
cp ./submission/efficientnet_v2_s/'(456, 456)'/*.csv  ./submission/
cp ./submission/regnet_y_8gf/'(384, 384)'/*.csv       ./submission/
cp ./submission/resnet_101/'(384, 384)'/*.csv         ./submission/
cp ./submission/resnext_50_32x4d/'(512, 512)'/*.csv   ./submission/
cp ./submission/wide_resnet_50_2/'(456, 456)'/*.csv   ./submission/
cp ./submission/shufflenet_v2_x2_0/'(512, 512)'/*.csv ./submission/
python test_ensemble.py

# outputs in ./submission/:
#   10fold_epoch10_submission.csv = hard voting
#   10fold_epoch11_submission.csv = soft voting
#   10fold_epoch12_submission.csv = mix voting  <- 8 models: 76.33% / 0.7640
# For the paper's best 6-model ensemble (76.93% / 0.7665), omit densenet_161 and
# wide_resnet_50_2 from the cp block above.

NOTES
-----
- main.py uses the paper's batch size 16; lower it (OAI-KL/main.py, batch_size = 16)
  if your GPU runs out of memory.
- main.py checkpoints every improved epoch as {N}fold_epoch{M}.pt under
  ./models/<model>/(<size>, <size>)/; test_auto.py skips CSVs already generated.
- Re-running test_ensemble.py without clearing ./submission/*.csv would include its
  own previous outputs as ensemble members.

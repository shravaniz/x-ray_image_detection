Knee KL Grade Classification - Commands
========================================

Repo   : https://github.com/shravaniz/x-ray_image_detection
Paper  : https://doi.org/10.1038/s41598-023-50210-4  (Pi et al., Sci Rep 13:22887, 2023)
Targets: 6-model mix voting 76.93% acc / 0.7665 F1 | 8-model mix voting 76.33% / 0.7640

Two size sets exist in this repo:
  A) Paper Table-3 optimized (best square) sizes - used in the Windows commands below:
     DenseNet-161 512 | EfficientNet-b5 448 | EfficientNet-V2-s 456 | RegNet-Y-8GF 384
     ResNet-101 384 | ResNext-50-32x4d 512 | Wide-ResNet-50-2 456 | ShuffleNet-V2-x2-0 512
  B) train_paper_ensemble.py OPTIMIZED_MODELS list (older MODEL_DETAILS.md sizes, + 3 ViTs).

$models = @(@('densenet_161',512), @('efficientnet_b5',448), @('efficientnet_v2_s',456), @('regnet_y_8gf',384), @('resnet_101',384), @('resnext_50_32x4d',512), @('wide_resnet_50_2',456), @('shufflenet_v2_x2_0',512))

3) STEP BY STEP - TTA test predictions + per-model scores
---------------------------------------------------------
# TTA inference: one CSV per checkpoint -> ./submission/<model>/(<size>, <size>)/
foreach ($m in $models) { python test_auto.py -m $m[0] -i $m[1] }

# per-model accuracy / F1
foreach ($m in $models) { python score_auto.py -m $m[0] -i $m[1] -t 0.65 }


4) STEP BY STEP - ensemble (paper's final 6 models, mix voting)
---------------------------------------------------------------
# test_ensemble.py reads EVERY csv in the flat ./submission/ folder
Remove-Item ./submission/*.csv -Force -ErrorAction SilentlyContinue
Copy-Item "./submission/efficientnet_b5/(448, 448)/*.csv"    ./submission/
Copy-Item "./submission/efficientnet_v2_s/(456, 456)/*.csv"  ./submission/
Copy-Item "./submission/regnet_y_8gf/(384, 384)/*.csv"       ./submission/

# setup (once per shell)

2) STEP BY STEP - train all 8 CNNs at the paper's Table-3 sizes (size set A)
----------------------------------------------------------------------------
cd /home/dumalkar/Documents/x-ray_image_detection/OAI-KL

for m in densenet_161:512 efficientnet_b5:448 efficientnet_v2_s:456 \
         regnet_y_8gf:384 resnet_101:384 resnext_50_32x4d:512 \
         wide_resnet_50_2:456 shufflenet_v2_x2_0:512; do

  python main.py -m "$name" -i "$size" \
    --data-dir ../KneeXrayData/ClsKLData/kneeKL299/train \
    --class-weighting none --skip-test-evaluation

3) STEP BY STEP - per-model evaluation + ensemble (soft voting)
---------------------------------------------------------------
# per-model held-out test metrics (averages the 5 {N}fold_best.pt checkpoints)
for m in densenet_161:512 efficientnet_b5:448 efficientnet_v2_s:456 \
         regnet_y_8gf:384 resnet_101:384 resnext_50_32x4d:512 \
         wide_resnet_50_2:456 shufflenet_v2_x2_0:512; do
  name="${m%%:*}"; size="${m##*:}"
  python evaluate.py -m "$name" -i "$size" --data-dir ../KneeXrayData/ClsKLData/kneeKL299/test
done

# ensemble: paper's final 6 models (add densenet_161:512 wide_resnet_50_2:456 for 8)
python evaluate_ensemble.py \
  --members efficientnet_b5:448 efficientnet_v2_s:456 regnet_y_8gf:384 \
           resnet_101:384 resnext_50_32x4d:512 shufflenet_v2_x2_0:512 \
  --data-dir ../KneeXrayData/ClsKLData/kneeKL299/test

# NOTE: hard/soft/mix voting via test_ensemble.py needs the ./KneeXray/train/train.csv and
# ./KneeXray/test/test_correct.csv layout, which currently exists only on the Windows machine.

===============================================================================
NOTES (both platforms)
===============================================================================
- main.py deletes existing *fold_best.pt when it starts a model: an interrupted model
  restarts from fold 1. run_pipeline.ps1 skips models whose 5 folds are complete.
- Windows GPU: Quadro T1000 (4 GB) -> batch size 8 (main.py default).
- test_auto.py is idempotent (skips CSVs already generated).
- Re-running test_ensemble.py without clearing ./submission/ would include its own
  previous outputs as ensemble members.
- main.py's built-in post-training evaluation is skipped (--skip-test-evaluation) on
  both platforms: evaluate.py's hardcoded default test path does not match either
  machine. Use the explicit evaluate.py / evaluate_ensemble.py --data-dir instead.
